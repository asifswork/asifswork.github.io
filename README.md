# Asif GitHub Pages Site

A minimal static site for GitHub Pages.

## Publish options

### User site
Repository name: `asifswork.github.io`

### Project site
Any repo name works; publish from the default branch root or `/docs`.

## Structure

- `index.html` — home page
- `style.css` — shared styles
- `notes/` — simple daily notes pages

## Updating

Edit `index.html` to update the home page and add new files under `notes/` for daily entries.
